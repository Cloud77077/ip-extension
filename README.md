## Features

- HTTP, HTTPS, SOCKS4, and SOCKS5 proxy configuration.
- Optional proxy username/password authentication.
- Host, protocol, and port validation.
- <local> bypass support.
- Optional proxy-country lookup through [ipwho.is](https://ipwho.is/).
- Optional timezone matching for the active HTTP/HTTPS tab.
- One-click disconnect to clear proxy state and stored connection data.
- Chrome/Chromium and Firefox packaging from the same source tree.

> [!NOTE]
> Timezone matching uses the browser debugging interface for the active HTTP/HTTPS tab. It does **not** change the operating-system timezone or every browser tab.

## Installation

### Chrome, Chromium, Edge, and Brave

1. Open [GitHub Releases](../../releases).
2. Download **ip-extension-chrome.zip** from the latest release.
3. Extract the ZIP.
4. Open the browser's extensions page, such as `chrome://extensions`.
5. Enable **Developer mode**.
6. Select **Load unpacked** and choose the extracted folder.
7. Pin **IP Extension**.

### Firefox

1. Open [GitHub Releases](../../releases).
2. Download **ip-extension-firefox.zip**.
3. Extract the ZIP.
4. Open `about:debugging#/runtime/this-firefox`.
5. Select **Load Temporary Add-on**.
6. Choose the extracted `manifest.json`.

> [!WARNING]
> Firefox's normal persistent distribution requires Mozilla's signing/distribution process. The release ZIP is suitable for unpacked/temporary developer installation.

### Mobile browsers

Unpacked extension support depends on the browser and version. A desktop Chrome extension ZIP cannot be assumed to install on Android or iOS.

## Proxy configuration

| Field | Meaning |
|---|---|
| Protocol | HTTP, HTTPS, SOCKS4, or SOCKS5 |
| Host | Proxy hostname or IP address |
| Port | Proxy port from 1 to 65535 |
| Username | Optional proxy authentication username |
| Password | Optional proxy authentication password |

Use proxy providers you trust. A proxy can observe traffic that is not protected by end-to-end encryption.

## Authentication

Proxy credentials are stored in extension-local browser storage because the browser needs them to answer proxy authentication challenges.

> [!CAUTION]
> Do not put proxy credentials, API keys, cookies, or other secrets into GitHub issues, README examples, source files, or commits.

## Timezone matching

When enabled, IP Extension requests the proxy's public location from [ipwho.is](https://ipwho.is/) and can apply the returned timezone to the active HTTP/HTTPS tab.

The feature requires the browser `debugger` permission and may display a browser debugging indicator.

It is intentionally limited to the active tab. It does not change the device's system timezone.

## Privacy and security

- Location lookup is optional and uses [ipwho.is](https://ipwho.is/).
- Proxy credentials remain in extension-local storage.
- The extension does not need an external account or API key.
- Prefer HTTPS websites when using a proxy.
- Disconnect the proxy when it is no longer needed.
- Browser or enterprise policies can prevent proxy control.

## Build from source

No npm installation is required.

```bash
bash ./scripts/package.sh chrome
bash ./scripts/package.sh firefox
```

Generated files:

- `dist/ip-extension-chrome.zip`
- `dist/ip-extension-firefox.zip`

The `dist/` directory is ignored by Git.

## Release system

The [release workflow](./.github/workflows/release.yml) validates the source, builds both ZIP packages, verifies that the ZIPs are readable and contain an **IP Extension** manifest, then publishes them to the GitHub Release.

The source repository intentionally does **not** contain generated ZIP, CRX, or XPI packages.

> [!TIP]
> For a release, use the GitHub Actions workflow rather than uploading manually. This keeps the repository source-only and makes the downloadable packages reproducible.

## Troubleshooting

**The proxy connects but websites do not load**

Check the protocol, host, port, credentials, and whether the proxy provider actually supports the selected protocol.

**Location detection fails**

The location lookup depends on the configured proxy path and the external [ipwho.is](https://ipwho.is/) service. If the request cannot reach the service or no timezone is returned, location matching cannot be applied.

**Timezone matching does not work**

The active tab must be an HTTP/HTTPS page and the browser must permit the extension's debugging permission.

**The extension cannot change the proxy**

Another extension, enterprise policy, or browser configuration may control the browser's proxy settings.
